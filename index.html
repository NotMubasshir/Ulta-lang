Overview

Ulta is an interpreted language. Source code is parsed into statements and then executed by the interpreter.

Statements normally end with semicolons. Blocks use curly braces.

Important: The current engine reverses statements inside blocks and function bodies.

Installation Guide

Follow these steps to install Ulta from the GitHub repository.

1. Install Node.js

Install Node.js from the official Node.js website. npm is included with Node.js.

Check Node.js and npm
node --version
npm --version

2. Install Git

Install Git and verify that it is available.

Check Git
git --version

3. Clone the repository

Terminal
git clone https://github.com/notmubasshir/Ulta-lang.git
cd Ulta-lang

4. Install dependencies

Terminal
npm install

5. View available commands

Terminal
npm run

This command displays the scripts configured in the project.

6. Start the development server

Terminal
npm run dev

Open the local URL shown in the terminal.

7. Build the project

Terminal
npm run build

8. Preview the production build

Terminal
npm run preview

Common installation problems

  • npm is not recognized: install Node.js and restart Visual Studio Code.
  • Cannot find module: make sure the terminal is inside the Ulta-lang folder.
  • Dependencies are missing: run npm install again.
  • Unknown npm command: run npm run to see the available scripts.

Variables

Use banao to create a variable. Assignment updates an existing variable.

variables.ulta
banao score = 10;
score = score + 5;
dekhao score;

Arithmetic

Ulta supports addition, subtraction, multiplication, division, and remainder.

math.ulta
banao a = 8;
banao b = 3;

dekhao a + b;
dekhao a - b;
dekhao a * b;
dekhao a / b;
dekhao a % b;

Conditions

Use jodi for a condition and nahole for the alternative branch.

conditions.ulta
banao x = 7;

jodi x > 5 {
    dekhao "besh bhalo";
}
nahole {
    dekhao "abar chesta koro";
}

Loops

Use jotokhon to repeat a block while its condition is true.

loops.ulta
banao x = 0;

jotokhon x < 3 {
    x = x + 1;
    dekhao x;
}
Remember: Statements inside the loop execute from bottom to top.

Functions

Declare a function using kaaj. Function parameters are written inside parentheses.

functions.ulta
kaaj greet(name) {
    dekhao "Hello, " + name;
}

greet("Bangladesh");

The Purno Ongsher Gimmick

Ulta reverses parsed statements inside blocks and function bodies. This is an intentional language rule.

reverse.ulta
banao x = 0;

jotokhon x < 3 {
    dekhao x;
    x = x + 1;
}

In this example, the assignment may execute before the output statement because the block is reversed.

Error Messages

Common errors usually come from invalid syntax, missing variables, missing functions, or incomplete blocks.

Example error
bhul: ei variable ba value pawa jay nai (score).
  • Check spelling of variable names.
  • Check that every block has a closing brace.
  • Check quotation marks around text.
  • Check function argument counts.
  • Check that assignments contain an equals sign.
