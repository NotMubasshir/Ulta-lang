Overview

Ulta is an interpreted programming language. Source code is parsed into statements and then executed by the interpreter.

Ulta uses Banglish-inspired keywords such as banao, dekhao, jodi, nahole, jotokhon, and kaaj.

Statements normally end with semicolons. Blocks use curly braces.

Important: Ulta's defining gimmick is that statements inside blocks and function bodies execute in reverse order.
Purno Ongsher: The reverse execution behavior is an intentional language rule rather than a playground bug.

Installation Guide

Follow these steps to install Ulta from the GitHub repository.

1. Install Node.js

Install Node.js. npm is included with Node.js.

Check Node.js and npm 
node --version
npm --version

2. Install Git

Check Git 
git --version

3. Clone the repository

Terminal 
git clone https://github.com/notmubasshir/Ulta-lang.git
cd Ulta-lang

4. Install dependencies

Terminal 
npm install

5. View available commands

Terminal 
npm run

6. Start development server

Terminal 
npm run dev

7. Build

Terminal 
npm run build

8. Preview

Terminal 
npm run preview

Common installation problems

  • npm is not recognized: install Node.js and restart VS Code.
  • Cannot find module: make sure the terminal is inside the Ulta-lang folder.
  • Dependencies are missing: run npm install again.
  • Unknown npm command: run npm run.

Basic Syntax

A simple Ulta program is made from declarations, assignments, output statements, blocks, and function calls.

basic.ulta 
banao x = 10;
x = x + 5;
dekhao x;

Semicolons

Simple statements are normally terminated with ;.

Blocks

Conditional, loop, and function bodies use { ... }. 

jodi x > 5 {
    dekhao x;
}

Comments

The current TypeScript grammar should be treated as the authoritative implementation. Do not rely on undocumented comment syntax.

Variables

Use banao to declare a variable. Assignment changes an existing variable.

variables.ulta 
banao score = 10;
score = score + 5;
dekhao score;

Variable naming rules

  • A name may begin with a letter or underscore.
  • The remaining characters may be letters, numbers, or underscores.
  • A variable cannot start with a number.
  • Reserved language keywords cannot be used as variable names.
valid 
banao score = 10;
banao player_name = "Mubasshir";
banao _value = 20;

Data Types

Ulta values can be:

  • Numbers
  • Strings
  • Booleans
  • null

Boolean values

Ulta supports the Banglish boolean names sotti and bhul. 

banao a = sotti;
banao b = bhul;

dekhao a;
dekhao b;

Null 

banao value = null;
dekhao value;

Strings

Strings may use single or double quotation marks. 

dekhao "Hello";
dekhao 'Bangladesh';

String escapes

Supported escapes include:

  • \n — newline
  • \t — tab
  • \" — double quote
  • \' — single quote
  • \\ — backslash 
dekhao "Hello\nBangladesh";
dekhao "Name:\tUlta";

Arithmetic

Ulta supports:

  • + addition / string concatenation
  • - subtraction
  • * multiplication
  • / division
  • % remainder 
banao a = 8;
banao b = 3;

dekhao a + b;
dekhao a - b;
dekhao a * b;
dekhao a / b;
dekhao a % b;

String concatenation 

banao name = "Ulta";
dekhao "Hello, " + name;
Arithmetic restriction:

Subtraction, multiplication, division, and modulo require numeric operands.

Conditions

Use jodi for a condition and nahole for the alternative branch. 

banao x = 7;

jodi x > 5 {
    dekhao "besh bhalo";
}

nahole {
    dekhao "abar chesta koro";
}

Comparisons

  • ==
  • !=
  • >
  • <
  • >=
  • <=

Logical operators

  • && — AND
  • || — OR
  • ! — NOT 
banao age = 18;
banao student = sotti;

jodi age >= 16 && student == sotti {
    dekhao "allowed";
}

Loops

Use jotokhon to repeat a block while its condition remains true.

loops.ulta 
banao x = 0;

jotokhon x < 3 {
    x = x + 1;
    dekhao x;
}
Important: Statements inside the loop body execute from bottom to top because the block is reversed.

The interpreter limits a loop to 1000 iterations.

Functions

Declare a function using kaaj.

functions.ulta 
kaaj greet(name) {
    dekhao "Hello, " + name;
}

greet("Bangladesh");

Multiple parameters 

kaaj add(a, b) {
    dekhao a + b;
}

add(10, 20);

Function rules

  • Parameters must have valid variable names.
  • Duplicate parameter names are rejected.
  • A function may have at most 20 parameters.
  • The number of arguments must exactly match the number of parameters.
  • Function calls do not produce expression return values.
  • Function execution is affected by reverse block execution.
  • Maximum function call depth is 100.

Scope

Function calls create a local scope based on the caller's current scope.

Function arguments are evaluated in the caller's scope before parameters are assigned. 

banao x = 10;

kaaj show(value) {
    dekhao value;
}

show(x);

The Purno Ongsher Gimmick

Ulta reverses parsed statements inside blocks and function bodies.

This is the core joke and defining behavior of the language.

reverse.ulta 
banao x = 0;

jotokhon x < 3 {
    dekhao x;
    x = x + 1;
}

The body is parsed and then executed in reverse order. Therefore the assignment can occur before the output statement.

Purno Ongsher Engine: "Ulta" is not merely the name — execution inside blocks is intentionally ulta.

Interpreter Limits

Limit Value Purpose
Loop iterations 1000 Prevents runaway loops.
Function call depth 100 Prevents uncontrolled recursion.
Function parameters 20 Keeps declarations manageable.

Bangla Error Messages

Ulta's interpreter uses structured error codes. Each error contains a code, a Banglish/Bangla message, and a hint explaining how to fix it.

Error format: 
[E###] Line N: message
  Code: source line
  Hint: what to do

The following reference documents the complete E004–E044 error range used by the TypeScript interpreter.
